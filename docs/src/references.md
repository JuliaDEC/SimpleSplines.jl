# References

The standard references for spline theory are de Boor
[deBoor:2001:PracticalGuideToSplines](@cite) and Schumaker
[Schumaker:2007:SplineFunctions](@cite). The recursion this package evaluates is Cox's and de
Boor's [Cox:1972:NumericalEvaluationOfBSplines](@cite),
[deBoor:1972:OnCalculatingWithBSplines](@cite). Piegl and Tiller
[PieglTiller:1997:NURBSBook](@cite) treat the geometric-modelling side, which this package
deliberately does not; Höllig [Hoellig:2003:FiniteElementMethodsWithBSplines](@cite) and
Cottrell, Hughes and Bazilevs [Cottrell:2009:IsogeometricAnalysis](@cite) treat the
finite-element and isogeometric settings it is written for. Basis recombination as a device for
imposing boundary conditions is discussed by Boyd [Boyd:2001:ChebyshevFourier](@cite).
