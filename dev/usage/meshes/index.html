Meshes

A Mesh is a subdivision of a closed interval $[a,b]$ into n cells by n+1 breakpoints. It is geometry alone: it carries no degree and no boundary condition, and the same mesh serves a clamped, a recombined and a periodic basis.

using SimpleSplines

The four families

meshbreakpointsrefining n givesuse it for
UniformMesh$y_i = a + (i-1)h$a uniform refinementordinary computation — but its periodic assemblies are circulant, so it confirms some identities for the wrong reason
GradedMeshthe image of a uniform mesh under one fixed smooth mapa genuine mesh familymeasuring convergence rates
RandomMeshperturbed cell widths from a seeded streaman unrelated meshproperties that must hold on any mesh
GeneralMeshwhatever you passwhatever you passa subdivision none of the three describes

The distinction between the first three is about what is being tested, not about the discretisation. A convergence rate measured across a family of RandomMeshes means nothing, because each n gives a different mesh rather than a refinement of the previous one; that is what GradedMesh is for. Conversely, an identity checked only on a UniformMesh may hold there because the assemblies are circulant and fail everywhere else, which is what RandomMesh catches.

[(nameof(typeof(m)), ncells(m), round(meshwidth(m); digits = 4))
 for m in (UniformMesh(8, 0 .. 1), GradedMesh(8, 0 .. 1), RandomMesh(8, 0 .. 1))]
3-element Vector{Tuple{Symbol, Int64, Float64}}:
 (:UniformMesh, 8, 0.125)
 (:GradedMesh, 8, 0.1385)
 (:RandomMesh, 8, 0.1455)

Constructors

UniformMesh(n, domain)                                  # UniformMesh(n) is [0, 2π]
GradedMesh(n, domain;  amplitude = 0.12)
RandomMesh(n, domain;  seed = 1, spread = 0.6)
GeneralMesh(breakpoints)

Each also has a {T} form — UniformMesh{Float32}(8, 0 .. 1) — for fixing the breakpoint element type explicitly.

Three ways to write the domain

A ClosedInterval, a two-tuple, or a bare number standing for $[0, L]$. The last is kept because UniformMesh(16, 2π) is the common periodic case.

UniformMesh(8, 0 .. 1) == UniformMesh(8, (0, 1)) == UniformMesh(8, 1)
true
domain(UniformMesh(8)), domain(UniformMesh(4, -10 .. 10))
(0.0 .. 6.283185307179586, -10.0 .. 10.0)

.. is re-exported, so using SimpleSplines is enough to write an interval; so are leftendpoint and rightendpoint.

leftendpoint(domain(UniformMesh(4, -10 .. 10))),
rightendpoint(domain(UniformMesh(4, -10 .. 10)))
(-10.0, 10.0)

Element types

An integer domain is promoted to a float, because the breakpoints of a subdivision of it are not integers — otherwise UniformMesh(4, 0 .. 1) would try to store 0.25 in an Int and throw an InexactError from a long way away. Rational and extended-precision types are left alone, since they are closed under the division breakpoints performs and narrowing them would discard the exactness that is the reason for using them.

eltype(UniformMesh(4, 0 .. 1)),
eltype(UniformMesh(4, 0 .. 1//1)),
eltype(UniformMesh(4, big(0.0) .. big(1.0)))
(Float64, Rational{Int64}, BigFloat)

meshwidth is the largest cell, not the average: for that mesh it is 10.0, not 40/6.

`breakpoints` must not be mutated

For GradedMesh, RandomMesh and GeneralMesh this returns the mesh's own array rather than a copy, which is what keeps findcell off the allocator on the innermost loop of a particle deposition. Writing to it corrupts the mesh, and silently: the domain and cell count are unchanged so nothing rejects the result, while hash and == now report a different mesh. UniformMesh computes its breakpoints from a closed form and hands back a fresh vector, but that is an implementation detail, not a licence. Take a copy if you need to modify it.

Equality is geometric, isequal is not

== and hash compare the domain and the breakpoints. isequal also compares the type, because the mesh type selects the assembly path — an equally spaced GeneralMesh deliberately does not take the CirculantMass route that a UniformMesh with the same breakpoints does.

u = UniformMesh(4, 0 .. 1)
g = GeneralMesh(collect(range(0, 1; length = 5)))
u == g, u ≈ g, isequal(u, g)
(true, true, false)

So the two are interchangeable as values and distinct as dictionary keys, and an equally spaced GeneralMesh is a legitimate way to force the general assembly path in a test.

Keyword arguments worth knowing

GradedMesh's amplitude is the $a$ in the map $s \mapsto s + (a/2\pi)\sin 2\pi s$. It must satisfy $|a| < 1$ for the map to stay increasing. The derivative of the map varies between $1-a$ and $1+a$, so the ratio of the widest to the narrowest cell approaches $(1+a)/(1-a)$ as the mesh is refined — the two below differ because a cell width is a finite difference of the map, not its derivative.

w = diff(breakpoints(GradedMesh(12, 0 .. 1; amplitude = 0.4)))
maximum(w) / minimum(w), (1 + 0.4) / (1 - 0.4)
(2.236098620152206, 2.3333333333333335)

RandomMesh's widths are $1 + \sigma r_i$ with $r_i$ uniform on $[0,1)$ and spread $= \sigma$, rescaled to fill the domain. The stream is seeded, so the mesh is reproducible; a different seed gives a different mesh.

breakpoints(RandomMesh(4, 0 .. 1; seed = 7)) ==
    breakpoints(RandomMesh(4, 0 .. 1; seed = 7)),
breakpoints(RandomMesh(4, 0 .. 1; seed = 7)) ==
    breakpoints(RandomMesh(4, 0 .. 1; seed = 8))
(true, false)

for bad in (() -> UniformMesh(0, 0 .. 1),

    () -> RandomMesh(4, 0 .. 1; spread = -1),
    () -> GeneralMesh([0.0]),
    () -> GeneralMesh([0.0, 0.5, 0.5, 1.0]),

        bad()
    catch err

    end
end

A repeated breakpoint is rejected rather than tolerated: it is a cell of zero width, which the Cox-de Boor recursion would silently skip, leaving a basis whose dimension does not match its knot vector. Multiplicity belongs in the knot vector, where the basis puts it, not in the mesh.

Finding a cell

findcell returns the index of the cell containing a point, in 1:ncells. The cells are half-open except for the last, which is closed, so the right endpoint belongs to cell n. A point outside the domain is clamped to the nearest cell.

u8 = UniformMesh(8, 0 .. 1)
findcell.(Ref(u8), [0.0, 0.06, 0.125, 0.99, 1.0, 5.0, -3.0])
7-element Vector{Int64}:
 1
 1
 2
 8
 8
 8
 1

On a UniformMesh this is a division and needs no breakpoint vector at all; on the others it is a searchsortedlast. Both are allocation-free when called on a basis, which caches the breakpoints — see Bases.
